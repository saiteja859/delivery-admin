# delivery-admin

Admin & Delivery portals for the Shop All Goods ecosystem.

## Structure
- **AdminPortal**: React + Vite frontend for administrators.
- **AdminPortalBackend**: Node.js / Express backend API for the admin portal.
- **DeliveryPortal**: React + Vite frontend for delivery partners.
- **DeliveryPortalBackend**: Node.js / Express backend API for delivery tracking and orders.
